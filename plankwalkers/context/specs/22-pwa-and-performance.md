## Goal

Coral Corsairs becomes an installable web app:
- It has its own icon. It opens fullscreen in landscape and plays with no
  network after the first visit.
- It asks the browser once to keep the player's saved levels.

The unit also delivers the tools to measure performance: a `?perf` frame-time
readout and a stress level. It uses them to record the allocation and frame-time
numbers owed since Unit 21 (issue 39), and to fix issue 33.

Everything is verified **on this PC**. Deployment is not part of this unit: the
phone install and the phone frame-time target are checked in the deploy step that
follows, because a service worker needs HTTPS anywhere except `localhost`.

## Measured Facts

Measured by Claude on 2026-10-07. Do not re-derive them; if one looks wrong, stop
and ask.

- **The build output** (`dist/`) is 98 files, about 1.9 MB:
  - `index.html`;
  - one JS and one CSS bundle in `assets/`;
  - `fonts/PixelifySans-Regular.woff2`;

- **Vite 8 `closeBundle`.** A plugin's `closeBundle` hook runs once after a
  successful build and sees all 98 files, including the copied `public/` files.
  Checked with a probe plugin.
- **Boot loads every sprite** (`loadAtlas`) **and every sound** (`audio.load`)
  before the title appears. Only CSS `url()` images and the font load later, and
  their paths are unhashed. So when a service worker replaces itself under a
  running page, nothing the page still needs goes missing.
- **Icon source:** `Captain Clown Nose/Sprites/Captain Clown Nose/Captain Clown
  Nose without Sword/01-Idle/Idle 01.png`, which is 64 × 40. Its opaque art is
  **x 20, y 4, w 24, h 28**, the same bounds `2-architecture.md` gives for the
  player hitbox measurement.
  - `player/idle` already consumes this file, so asset coverage stays
    **430 / 1195**.
  - The build's `consume()` guard throws on a second use, so the icons must not
    call it.
- **Sky colour** `#ddc6a1` (`--sky`), **ink** `#33323d` (`--ink`).
- **The validator** (`findProblems`) checks only these for spawn and goal:
  - spawn not in terrain, not in water, and not in the goal's cell;
  - goal not in terrain.

  A spawn or goal in a platform cell is allowed.
- **Shooter sense ranges:** cannon 208 px, seashell 176 px. Walker sense ranges:
  56–96 px.
- **Decor rebuilds** in the maker (`decorVisual.sync`) happen on decor paint and
  erase, and on undo and redo (`maker-scene.js`, `decorDirty`). They never happen
  per frame.
- **Issue 33:** `physics.js` `cellRangeX`/`cellRangeY` return a new two-element
  array, and are called 11 times across `resolveH`, `resolveV`,
  `resolveSemiSolid`, `checkSolid`, `checkFloor` and the wall checks. Every one

**3. `tools/service-worker.template.js`** (new). Exactly this, apart from comment

```js
// Coral Corsairs service worker. tools/pwa-plugin.mjs copies this into
// dist/sw.js at build time and replaces the two placeholders. Not imported by src/.
const VERSION = '__CC_VERSION__';
const PRECACHE = __CC_PRECACHE__;
const CACHE_PREFIX = 'cc-';
const CACHE = CACHE_PREFIX + VERSION;

self.addEventListener('install', (event) => {
  event.waitUntil(
    caches.open(CACHE)
      .then((cache) => cache.addAll(PRECACHE))
      .then(() => self.skipWaiting()),
  );
});

self.addEventListener('activate', (event) => {
  event.waitUntil(
    caches.keys()
      .then((keys) => Promise.all(keys
        .filter((key) => key.startsWith(CACHE_PREFIX) && key !== CACHE)
        .map((key) => caches.delete(key))))
      .then(() => self.clients.claim()),
  );
});

self.addEventListener('fetch', (event) => {
  const request = event.request;
  if (request.method !== 'GET') return;
  if (new URL(request.url).origin !== self.location.origin) return;
  // The game is one page: every navigation, with or without ?perf, gets the
  // cached shell.
  const key = request.mode === 'navigate' ? '/index.html' : request;
  event.respondWith(caches.match(key).then((hit) => hit || fetch(request)));
});
```

- Cache-first; there is no runtime caching of files that are not precached.
- `skipWaiting` is safe because boot preloads every sprite and sound (Measured
  Facts).

```js
 * Excludes the worker itself and source maps.

/**
 * Cache version: the first 12 hex characters of a SHA-256 over every
 * (path, content) pair in path order, so any changed byte or renamed file

 * @param {{ path: string, bytes: Uint8Array }[]} entries
 * @returns {string}
 */

/**
 * @param {string} template service-worker.template.js source
 * @param {string} version
 * @param {string[]} urls

export function renderServiceWorker(template, version, urls) { … }

/** @returns {import('vite').Plugin} */
export function pwaPlugin() { … }
```

- `precacheUrls`:
  - drops `sw.js` and anything ending in `.map`;
  - prefixes `/`;
  - sorts with the default string order.
- `cacheVersion`:
  - sorts by path;
  - for each entry, hashes the path, then one `\0` byte, then the bytes, then
    one `\0` byte, with `node:crypto` `createHash('sha256')`;
  - returns `digest('hex').slice(0, 12)`.
- `renderServiceWorker`:
  - replaces `'__CC_VERSION__'` (with its quotes) with `JSON.stringify(version)`;
  - replaces `__CC_PRECACHE__` with `JSON.stringify(urls)`.
- `pwaPlugin()`:
  - `name: 'coral-corsairs-pwa'`, `apply: 'build'`;
  - `configResolved(config)` stores `path.resolve(config.root,
    config.build.outDir)`;
  - `closeBundle()`:
    1. walk outDir recursively, posix-relative;
    2. build the precache list and the version from the **precached** files;
    3. read the template next to this file;
    4. write `outDir/sw.js`;
    5. log one line: `pwa: sw.js caches N files (version V)`.

### C — Keep Saved Levels (Storage Persistence)

**`src/storage/persist.js`** (new):

```js
/**
 * Ask the browser once per page session to keep this site's storage, so Safari's
 * seven-day eviction cannot take a player's levels (watchlist 13). Chrome and
 * Safari decide silently; Firefox may prompt once. Never throws.
 *
 * @param {() => (StorageManager | undefined)} getManager e.g. `() => navigator.storage`; may throw
 */
export function createPersistRequest(getManager) {
  let asked = false;
  return {
    /** @returns {Promise<boolean | null>} null when not asked or unsupported */
    async request() {
      if (asked) return null;
      asked = true;
      /** @type {StorageManager | undefined} */
      let manager;
      try { manager = getManager(); } catch { return null; }
      if (!manager || typeof manager.persist !== 'function') return null;
      try {
        if (typeof manager.persisted === 'function' && await manager.persisted()) return true;
        return await manager.persist();
      } catch {
        return null;
      }
    },
  };
}
```

```js
/**

export function createFrameStats(size) {
  const work = new Float64Array(size);
  const interval = new Float64Array(size);
  let next = 0;
  let count = 0;
  return {
    /** @param {number} workMs @param {number} intervalMs */
    push(workMs, intervalMs) { … },

     * @param {{ avgWork: number, maxWork: number, fps: number, count: number }} out

```

- `push` writes at `next`, wraps it modulo `size`, and grows `count` up to `size`.
- `summarize` writes, over the stored frames:

  - `count`.
