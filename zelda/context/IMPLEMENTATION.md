# IMPLEMENTATION — what is built, and where

An index of the shipped systems: subsystem → file(s) → what it actually does and
which slice built it. Written so an agent can find the owner of a behaviour
without grepping 103 source files.

**The code is the truth; this is a map of it.** If the two disagree, the code
wins and this file needs a line changed. Add a row when a slice ships a new
system; edit the row when a later slice changes one.

Roadmap: `PLAN.md`. Why things are the way they are: `DECISIONS.md`. What
happened when: `HISTORY.md`. What is happening now: `STATUS.md`.
